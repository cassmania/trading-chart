# 트레이딩 챠트

실시간 코인 차트 + 지표 자동 백테스트 웹앱. GitHub Pages에 그대로 올리면 동작합니다.

## 기능
- 실시간 시세: USDT는 바이낸스(실패 시 OKX), KRW는 업비트 — REST로 1,000봉을 받고 WebSocket으로 실시간 갱신
- 멀티차트: 1·2·3·4·6·8 분할, 차트마다 심볼·시간봉 개별 설정, ⤢ 버튼으로 크게 보기
- 시간봉: 15분 · 1시간 · 4시간 · 12시간 · 일 · 주 · 월
- 자체 지표 1·2·3위 (헤더 '지표' 버튼으로 모든 차트에 적용, 기본 1위): 추세 합의 · 터틀 돌파 40/15 · 슈퍼트렌드 필터 — 8종목 × 1h·4h·12h·1d 백테스트에서 무작위 진입 기준선을 개발·검증 두 구간 모두 넘은 순 (`custom.js`)
- 바이낸스 실시간 매매 신호 피드: 차트 코인+관심종목+주요 코인 12종목 × 선택 봉(기본 1시간·4시간)을 확정봉마다 자체 1~3위 지표로 판정해 진입·청산·손절과 타점(진입·손절·1.5R/3R 목표)을 표시, 누르면 그 차트로 전환
- 매수·매도 마커에 체결 가격(타점) 표시
- 자동 추세선(지지 초록·저항 주황), 차트별 확대·축소·맞춤 버튼, 모바일에서 재생·확대 도구를 둘째 줄에 표시
- 지표 11종 자동 백테스트: 슈퍼트렌드+RSI, 슈퍼트렌드, EMA 9/21, MA 20/60, MACD, 돈치안, 파라볼릭 SAR, RSI 30/70, 볼린저 반전, 스토캐스틱, CCI
- 시장 국면(상승 추세 / 하락 추세 / 횡보)을 ADX·DI·EMA50으로 판정하고, 국면별로 검증 성과가 가장 좋은 지표를 차트에 자동 적용
- 워크포워드 검증: 과거 데이터로만 고른 지표를 다음 구간에 적용한 성과를 표시 (미래 참조 없음)
- 매수·매도·손절 타점 마커, 진입가·손절가·1차/2차 목표가 라인, VPVR POC·밸류 영역
- 롱만(현물) / 롱·숏(선물) 모드, 라이트·다크 모드, 모바일 대응

## 백테스트 규칙
봉 마감 신호 → 다음 봉 시가 체결, 수수료 편도 0.1%, 진입 시 2.5×ATR 손절 고정.
형성 중인 마지막 봉은 신호 계산에서 제외합니다. 점수는 승률 하한(Wilson 80%) × 손익비(PF) × 낙폭 패널티입니다.
